# 界面总览

主窗口从外到内分四层：顶栏、SOP 步骤带、主体、状态栏。主体由左侧导航、主页面、右侧参数停靠与助手边栏组成，主页面底部横跨时间轴。界面语言固定为简体中文，不提供切换。

## 顶栏与状态栏

顶栏左侧是应用名与菜单栏，菜单分为文件、视图、工具、帮助。文件菜单打开与保存情景、导出画布图片与动画。视图菜单控制侧边栏、参数停靠与助手边栏的显隐，也切换三个文档标签。工具菜单进入轨道保持与图表设置。帮助菜单检查更新、打开关于窗口。顶栏右侧显示当前时刻对应的 UTC 历元、助手边栏开关、主题切换、设置与关于按钮。

状态栏显示当前文档标签、任务运行状态、本地时间、UTC 时间、ET 秒、CPU 占用、内存占用与软件版本。时钟每秒刷新，性能数据每 2 秒从 Rust 壳采样一次。

## SOP 步骤带

顶栏下方的步骤带把界面操作固定为七个阶段：定基准、定任务、填参数、求解、校核、入库、情景。当前阶段高亮，已完成阶段显示勾选，各阶段右侧给出当前取值摘要，例如工具名、参数计数、结果条数与库记录数。

步骤带不是向导。点击任一阶段直接执行该阶段动作，不要求按顺序走完。运行前的硬校验结论也显示在这里：缺历元、缺参数或缺少上游轨道记录时，带内逐条列出阻断项，每条带一个补救按钮。阻断项非空时，求解按钮禁用，参数停靠的字段标红与步骤带使用同一份判定。

## 左侧导航

左侧导航常驻，上半部分是项目树，下半部分是工具列表。

项目树列出轨道库中的记录。每行提供星标、钉到画布、编辑备注、绘制所选与删除入口。星标是保留标签，只在该图标处设置。图钉把记录加入固定层，固定层最多 5 条，超出时提示但不改变已有选择。删除是物理删除，执行前要求确认。

工具列表按用户目标命名，共八项：轨道族生成、任务轨道设计、参数空间扫描、轨道保持、轨道预报、转移轨道设计、时空坐标转换、分区边界。选择工具会切换参数停靠中的表单，并清空上一次的参数与校验问题。

## 主页面与文档标签

主页面顶部是可开关的文档标签，分别是三维视图、轨道信息与轨道库。标签内容常驻挂载，关闭只从标签条收起。重新打开后回到收起前的状态，三维视图的场景与相机保持连续。

### 三维视图

三维视图由画布工具栏与 Three.js 画布组成。工具栏左侧选择视图系（会合系或惯性 GCRS）、投影（3D、XY、XZ、YZ）、中心（质心、地心、月心、L1、L2）与内容（全部、CR3BP、星历）。月心、L1 与 L2 是会合系概念，惯性视图下不可用。工具栏右侧提供适配、导出图片、导出动画、图表设置、保存情景与打开情景。

画布、时间轴、图层、配色与导出细节见 {doc}`visualization`。

### 轨道信息

轨道信息标签显示当前聚焦轨迹的几何、数据系、Jacobi 常数、点数与来源。画布轨道清单点选与画布拾取都会切到这里。清单同时显示当前画布上的轨迹条数与各条来源。

### 轨道库

轨道库标签由过滤条与记录详情组成，查询结果回灌左侧项目树。过滤条按族类型、平动点、Jacobi 区间、振幅区间与标签组合筛选，勾选仅看星标后只返回带星标的记录。

记录详情显示系统分类、谱系、标签与备注，并提供编辑入口。转移结果还会列出可行解对比，按 Δv 升序排列。过滤栏提供教学案例包导出。项目树在左侧常驻，本标签只管筛选与详情。

## 参数停靠

参数停靠位于主页面右侧，承载当前工具的参数、运行入口与画布轨道清单。宽度可拖动，可折叠，宽度与折叠状态持久化。

参数表单由工具的 JSON Schema 生成。字段类型对应数值框、下拉、勾选等控件。Optional 字段由勾选控制传不传值，勾选即传，不勾视为未设置。按 `orbit_type` 只显示当前族适用的字段，跨族字段不出现在表单里。数值框可切换显示单位，切换只改变显示数值，不改变物理量。

提交前做防呆校验。必填缺失、数值越界与互斥参数冲突会被拦下，问题在字段旁标红，同时进入步骤带的阻断项。运行期间按钮显示进度态，下方状态行滚动显示 sidecar 进度消息。计算失败时显示错误码与原因，不伪造成功。

## 助手边栏

助手边栏位于主页面右侧、参数停靠之外，可折叠、可拖宽。收起后会话与流式回复继续，订阅不中断。全应用只有一个助手实例，对话与画布并排可见。

助手以随应用分发的 pi 为会话运行时。模型服务、API key、provider 与思考档位由 pi 原生配置管理，应用不收集、不展示、不保存这些内容。设置弹窗的 AI 助手分区显示 pi 路径与 RPC 连接状态，并提供打开 pi 配置流程的按钮。首次使用在终端运行交互式 pi，完成 provider 登录。

输入区上方的配置条切换模型与思考档，选项与 pi 原生配置同源。只读工具免确认直接执行，包括轨道库查询、记录详情、情景列表与参数范围查询。计算与改库工具先在对话流中出工具卡片，完整展示参数，用户批准或拒绝。审批协议不携带改后的参数，因此卡片没有改参入口。完成后卡片折叠为单行摘要，显示工具名、状态与产物记录 id，可展开参数与结果摘要，也可跳到项目树查看产物。

会话跨重启持久化。会话切换器按最近活动倒序列出历史会话，可新建与续聊。pi 会话协议没有重命名与删除命令，界面不提供这两项操作。有回复进行中或确认未决时禁止切换会话。生成中仍可输入，发送即引导，pi 把新消息排到当前轮工具批之后继续，上下文保留。

已知限制：助手触发的长计算不显示真实进度，确认开始后不能取消。

## 设置

顶栏的设置按钮打开图表与界面偏好设置，包含三部分：

- 图表设置：字号、轨道线宽、Z 轴比例、网格量程、坐标轴与分区图层开关、画布背景色。修改即时生效并持久化。
- 星历内核状态：显示 SPICE 内核是否就绪。内核随安装包分发，正常安装下始终就绪，缺失通常意味着安装损坏或 `kernels/` 被删。
- AI 助手：pi 入口状态与原生配置流程，见上一节。
