# 快速上手

## 安装

从 [GitHub Releases](https://github.com/cislunarspace/CODE/releases) 下载对应平台的安装包。Windows x64 使用 `CODE_<版本>_x64-setup.exe`（NSIS，免管理员，装到当前用户目录）或 `.msi`。Linux amd64 与 aarch64 提供 AppImage、`deb` 与 `rpm`。安装包内含 e2m2e 运行时、AI 助手运行时 pi 与全套 SPICE 内核，安装后即可计算。

## 启动与界面

启动后先看顶栏下方的步骤带。它把操作固定为七步：定基准、定任务、填参数、求解、校核、入库、情景。步骤带不是向导，任何一步都可以直接点开。当前阶段高亮，未满足的前置条件列在带内，每条带补救按钮。

界面其余部分按职责分工。左侧导航上半是项目树，下半是工具列表。主页面用文档标签切换三维视图、轨道信息与轨道库。右侧参数停靠放当前工具的参数与运行按钮。助手边栏在最右侧，可收起。状态栏显示任务进度、时间、性能与版本。

## 生成一族轨道

以 Halo 族为例。

1. 在左侧工具列表选择轨道族生成。
2. 在右侧参数停靠把族类型设为 HALO，平动点设为 L2，填写振幅上限与成员数上限。轨道族生成是纯 CR3BP 计算，没有必填历元，定基准阶段自动完成。
3. 点求解。按钮下方状态行滚动显示 sidecar 进度。
4. 计算完成后，三维视图逐条画出族成员。切到轨道信息标签核对数据系、Jacobi 常数与点数。
5. 产物自动写入轨道库。切到轨道库标签，可按族类型、平动点、Jacobi 区间与振幅区间过滤。

## 浏览轨道库

轨道库标签的过滤条与左侧项目树联动。修改过滤条件后点查询，结果回灌项目树。点击任一记录，记录详情显示系统分类、谱系、标签与备注。点项目树上的图钉把记录加入固定层，固定层轨迹与后续计算结果同屏对照，最多 5 条。星标、备注与删除入口也都在项目树上。

固定层记录数大于零且时间轴处于 et 时钟模式时，可在画布工具栏保存情景。情景文件记录固定层记录引用、参考历元与播放配置，重新打开时按引用重建固定层并校准时间轴。
