# ADR 0034：界面围绕 SOP 组织（侧边栏 + 顶边栏 + 文档标签 + 参数停靠 + 助手边栏）

日期：2026-10-11

## 状态

已接受

## 背景

用户反馈三条，指向同一件事：界面没有主心骨。

1. 每个页面各自左右分栏（左参数右画布、左树右详情），切页后操作位置漂移，找不到“我现在该干什么”。
2. 特殊功能与常驻功能混在一处，缩放、导出、筛选、详情都挤在页面里，没有“弹窗承载一次性任务”的分工。
3. 视觉上仍有圆润与彩色块（开关胶囊、彩色元数据标签、主按钮投影），与 ADR 0020 的严肃线框语言不一致。

同时，仓库缺一份写下来的**标准操作流程**（SOP）：工具、轨道库、情景、历元这些概念在 CONTEXT.md 里有定义，但“用户按什么顺序使用它们”没有正典。界面因此只能按功能罗列，不能按流程组织。

外部参照：ATK（Aerospace Tool Kit）的离线帮助与 `UiATK.dll` 逆向（Ghidra 12.1.4 + GhidraMCP 无头分析，66058 个函数）。逆向实测的界面结构与文档描述有出入，以下以二进制为准：

- 主窗口是 `CMainWindow`（基类 `QMainWindow`，ctor `0x1801d31e0`）。所谓主菜单栏不是 `QMenuBar` 也不是 `QToolBar`（本地实现为 0 处），而是中央控件顶部的 `QTabWidget`（`ui+0x60`），九个命令页（Start / Edit / View / Insert / Outpput / Tool / AI / Integrating / About，其中第五项 Outpput 的拼写以二进制原文为准），每个命令页就是一组按钮。命令是标签页，视图是停靠面板与独立窗口。
- 停靠面板走两套机制：原生 `QDockWidget`（`splitWindow 0x1802169c0` 建 Object / Timeline View / Message / Globe Manager）与自研 `CAtkDockManager` 单例（`ATKUiDockManagerGet 0x18040fab0`，承载 2D/3D Graphics、Agent/Chat、Model Hub、Script Tool、对象属性与工具窗等）。
- 属性配置与一次性任务走模态对话框（`QDialog::exec` 判定，类名含 Dlg 的 38 个、Dialog 的 13 个），另有独立窗口（新建场景向导、坐标转换）。
- 状态栏（`initStatusBar 0x1801f7ca0`）由四个标签加两个工具按钮组成，按钮是“消息视图”“选中对象”这类跳转入口。
- 样式表可提取（`qRegisterResourceData` 段解析出 633 张 png 与两份 qss）。`flatwhite.qss` 的取值为灰阶线框：窗口底 `#d6d6d6`、控件面 `#ececec`、输入白底、文字纯黑、1px 边框，命令页选中态是实心蓝 `#0c62eb` 配白字加 4px 上圆角。
- 它的分工是：命令是标签页，对象与属性是停靠或对话框，视图文档可以多开。本仓库的布局与它不同（本仓库的标签页承载视图文档，命令走菜单栏），相同的是那份分工原则与灰阶线框的视觉基调。

## 决策

### 1. SOP 正典（七阶段，末尾循环）

1. 定基准：工具的参考历元参数（必填历元字段为空即算未定）。时间轴上的时刻是看图时刻，不替代参数（ADR 0021）。
2. 定任务：选择工具（轨道设计 / 族生成 / 转移设计 / 预报 / 保持 / 空间分区…）。
3. 填参数：参数面板按分支展开字段，缺项与越界当场标红。
4. 求解：提交到 e2m2e sidecar，进度回显示在按钮下方与状态栏。
5. 校核：画布与轨道信息标签核对结果（几何、类型、数据系、Jacobi、点数、来源）。
6. 入库：产物自动进轨道库（CONTEXT.md“记录”），可加星标、备注、分组。
7. 情景：钉住记录＋参考历元组成情景，保存/打开即重建固定层与时间轴（CONTEXT.md“情景”）。

第 7 步之后从“入库”回到第 2 步即复用（取库记录续算机动、保持、转移）。步骤带把这层循环写在最右，不设第 8 个阶段。

### 2. 布局：一个侧边栏、一个顶边栏、主页面标签、右侧两栏、底部两行

- 顶边栏：产品名、菜单栏（文件 / 视图 / 工具 / 帮助）、当前历元、助手开关、主题、设置、关于。菜单项只放已有动作，不放占位项。
- 步骤带：SOP 七阶段横向排在顶边栏下方。当前阶段高亮，点任一阶段执行该阶段动作（不是向导弹窗，任意步随时可跳）。
- 侧边栏：项目树（场景与库记录，常驻）＋ 动力学工具列表。可折叠，折叠态持久化。
- 主页面：文档标签（三维视图 / 轨道信息 / 轨道库），可开可关。标签内容常驻挂载，非激活 `display:none`。
- 参数停靠：右侧，宽度可拖、可折叠。内容为当前工具的参数、运行入口与画布轨道清单。
- 助手边栏：右侧，可收起。唯一实例，收起用 `display:none` 保活（不重挂载，订阅与流式回复不中断）。
- 时间轴条与状态栏：主页面底部两行。状态栏显示当前视图、任务、时间三口径、CPU／内存、版本。

### 3. 硬校验：阻断项集中一处呈现

运行前校验只做一次推导（`sop.ts` 的 `deriveSop`），参数面板内联红标、步骤带阻断清单、运行按钮禁用三处共用同一份结论。阻断项分三类，每条都带补救动作：

| 类型 | 触发 | 补救 |
|---|---|---|
| 历元 | 工具必填历元字段为空，且时间轴未选时刻 | 展开参数停靠（去选历元） |
| 参数 | 非历元的必填缺失或越界 | 展开参数停靠（去补参数） |
| 上游记录 | LGA/WSB 转移未选中目标轨道 | 展开侧边栏（去选记录） |

不按工具硬编码依赖表：历元依赖从工具 schema 的字段名与必填项推出，上游依赖从当前参数分支推出。星历内核状态不作为阻断项（哪些工具依赖内核无法从 schema 判定，编一张表等于编事实），内核缺失由 e2m2e 的 `KERNEL_NOT_FOUND` 明确报错。内核状态在设置面板展示。

### 4. 视觉：彩色只留给状态

- 主按钮去掉蓝色投影（`themeComponents.Button.primaryShadow`）。
- 开关去胶囊：antd Switch 根与滑块都是 100px 圆角，收到 2px（`flatSwitchStyles`）。
- 元数据标签改中性线框（`neutralTagStyle`）：族名、平动点、动力学能力这类描述性信息不再用蓝/青/绿/紫彩色块。彩色只用于状态（成功、失败、警告、进行中）。
- 计数徽标、助手状态点、进度条端点一并收方。
- 时间轴条配色随明暗主题（`--tod-accent` 与 `--tod-panel-bg`），不再写死深色底。浅色界面里它过去是一条跳出来的暗带。

## 后果

- 操作位置稳定：参数、运行、清单固定在右侧停靠。结果核对与库浏览是标签。一次性任务（导出动画、轨道保持、图表设置、关于、更新）仍是弹窗。
- 流程可见：新用户能看出“先定基准再跑”。老用户点阶段即跳转，不受向导干扰。
- 代价：主页面被切得更碎（1600px 宽下画布约 640px）。边栏与停靠都可折叠，且宽度持久化，缓解但不消除该代价。窄屏用户需要主动收起助手。
- 取舍记录：
  - 助手只保留边栏一种形态（唯一实例，收起时保活），不做独立标签页。同一会话在两个宿主里会挂载两份实例，事件订阅与流式回复会重复。术语沿用 CONTEXT.md 既有的 **助手边栏**，不为它另造“助手抽屉”这个名字。
  - 参数面板从左侧移到右侧。左停靠与项目树抢同一侧，且 ATK 的属性面板也在对象树同侧之外的独立区域。移到右侧后“先选树里的记录，再看右边的参数/详情”是一条直线。
  - `tod-page` 持久化键废弃（无兼容层），改为 `tod-doc-tabs` / `tod-doc-active`。侧边栏与助手边栏各有一对键。
- 未做：SOP 的阶段完成度不回写任何数据（不改记录、不改标签），纯界面状态。命令面板与键盘跳步未实现。ATK 状态栏里那种跳转按钮（消息视图、选中对象）没有采纳，本仓库的状态栏只读。

## 后续更新（2026-10-22）

ADR 0037 把视觉口径改为 LDC 风格（zinc 灰阶、中性主色、8–16px 圆角），本 ADR 第 4 条里“开关去胶囊”“计数徽标收方”两项随 0037 废止，“主按钮去投影”“元数据标签中性”“彩色只留给状态”“时间轴随主题配色”四项继续有效。布局与操作位置不变：顶边栏、SOP 步骤带、侧边栏、文档标签、参数停靠、时间轴、状态栏、助手边栏的结构仍是本 ADR 决定的。
