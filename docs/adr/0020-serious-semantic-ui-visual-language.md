# 0020. UI 视觉语言定为严肃语义色板

- 日期: 2026-08-25
- 状态: 已被 ADR 0037 取代（圆角、主色与开关胶囊口径；关闭位移动效与彩色只留给状态两条仍然有效）

界面自 PyQt 重构为 Tauri + Ant Design 6（ADR-0014/0015）后，沿用了 antd 默认的圆润亮色风格（8px 圆角、活泼的 `#1890ff` 主色）。为匹配轨道设计工具的严肃技术气质，我们有意偏离 antd 默认视觉：

- **直角**：全局 `borderRadius` 全系列（base/LG/SM/XS/Outer）统一降到 **2px**。
- **收敛语义色板**：整个界面只用黑/白/灰/红/蓝/绿/橙七种色相——红=错误、绿=成功、橙=警告、蓝=主色/信息，中性色沿用 antd 灰阶。主色蓝从 `#1890ff` 收敛为深蓝 `#0958d9`。
- 直接写死为主题 token 的新默认，不设用户配置项。

这是一处对 antd 默认风格的有意偏离。后续开发者看到直角与收敛主色时，不应将其"修复"回 antd 圆润默认——那不是 bug，是设计方向。

## 后续更新（2026-08-25）：深定制做实

首版只动了圆角与主色两组 token，实际观感与 antd 默认几乎无差别——2px 与 6px 圆角不并排对比不可辨，`#0958d9` 本就是 antd 官方 hover 深蓝。"卡通圆润感"的真正来源是动画、阴影、控件密度与字体，本版补齐为四项系统化定制，仍全部走主题 token，不引入用户配置：

- **去动画**：`motion: false`，按钮、弹窗、下拉的全部过渡缓动停用。
- **平面化**：`wireframe: true`，组件去渐变、阴影改边框式；浮层仅保留一层浅投影（`boxShadow` / `boxShadowSecondary`）。
- **高密度**：控件高度 32/24/40 收紧到 26/22/30，对齐桌面工具量级。
- **系统字体**：Segoe UI + 雅黑（`fontFamily` token 与 `index.html` 同步）。
