# ADR 0037：界面视觉语言改为 LDC 风格

- 日期：2026-10-22
- 状态：已接受
- 取代：ADR 0020 的视觉口径（圆角、主色、开关胶囊）

## 背景

当前视觉口径来自 ADR 0020 与 0034：直角 2px、去动画、线框化、深蓝主色、彩色只留给状态。落地后界面仍然偏工程灰。卡片、面板、顶边栏底色几乎相同，层次只靠 1px 描边区分。深蓝主色同时承担按钮、选中态与链接，与状态色放在一起时互相抢注意力。控件密度与字号已经收紧，但圆角与灰阶没有跟上，整体读起来像调试工具而不是产品。

用户要求参照本机参考目录 `_refs/workbuddy-manager` 里的 workbuddy-manager（该目录不在本仓库内）。其 README 的致谢一节写明界面设计令牌与浮动底栏组件来自 [linux-do/cdk](https://github.com/linux-do/cdk)：shadcn/ui 的 new-york 风格，Tailwind v4 的 zinc 中性灰阶，亮色为主、暗色可切，扁平克制、类 GitHub 的社区产品质感。它的 `web/app/globals.css` 是这套令牌的直接来源。

可迁移的是令牌与层级关系，不是布局：参照项目是顶部管理栏加居中内容，本仓库是桌面三栏控制台，布局与操作位置由 ADR 0034 决定，本次不改。

## 决策

1. 令牌层单点定义。`frontend/src/theme.ts` 提供色板与几何（`shellColors`）、antd token 映射（`themeTokens`）与 CSS 变量注入（`themeCssVars`，变量名 `--ldc-*`）。`frontend/src/ldc.css` 只消费变量，不重复定义颜色。时间轴、状态栏与助手边栏沿用的 `--tod-*` 旧名暂时与 `--ldc-*` 同源发布，改名留到这些消费端一并迁移时做。不引入 Tailwind 与 shadcn，不新增依赖。

2. 色板改用 zinc 中性灰阶：

   | 令牌 | 亮色 | 暗色 |
   |---|---|---|
   | 页面底 | `#ffffff` | `#09090b` |
   | 侧边栏与停靠面 | `#fafafa` | `#111113` |
   | 卡片 | `#ffffff` | `#18181b` |
   | 次级面（徽标、悬停） | `#f4f4f5` | `#1f1f23` |
   | 描边 | `#e4e4e7` | 10% 白 |
   | 主文字 | `#18181b` | `#fafafa` |
   | 次级文字 | `#52525b` | `#d4d4d8` |
   | 三级文字 | `#71717a` | `#a1a1aa` |

3. 主色改为中性色。控件主色在亮色下是近黑（`#18181b`），暗色下是近白（`#fafafa`），主色上的文字取反。蓝、绿、橙、红只承担语义：信息蓝 `#2563eb`／`#60a5fa`、成功绿 `#10b981`／`#34d399`、警告橙 `#f59e0b`／`#fbbf24`、错误红 `#ef4444`／`#f87171`。这让按钮获得参照项目的黑白质感，也让状态色重新成为界面上唯一的彩色来源。

4. 圆角分档：按钮与输入框 8px，卡片与面板 12px，行与徽标 6px，模态弹层 16px。下拉菜单与选择器浮层沿用 12px，提示气泡 6px，都不按模态弹层的档位放大。开关恢复胶囊。ADR 0020 的 2px 直角口径废止。

5. 投影收敛：控件无投影，卡片只靠描边，浮层一层柔和投影（亮色 `0 16px 40px rgba(24,24,27,0.12)`），弹窗遮罩用中性半透明而非纯黑。

6. 动效仍关闭 antd 的位移与缩放（`themeBehavior.motion`），交互反馈改为 120 ms 的颜色过渡（`.ldc-hover-row`）。

7. 密度不下调：控件高度 28/24/32，基础字号沿用用户设置（默认 12），面板与状态栏高度基本不变。参照项目的信息密度低于本工具，直接照搬会牺牲可用画布面积。

8. 字体沿用系统字体栈，`Inter` 只作为首选名参与匹配，不随安装包分发 Web 字体。

9. 布局与交互不变。顶边栏、SOP 步骤带、侧边栏、文档标签、参数停靠、时间轴、状态栏、助手边栏的结构、固定位置与可折叠行为仍由 ADR 0034 决定。

10. 公共构件收敛到 `ldc.css`：面板头、分区标题、徽标、可交互行、悬停外壳、表单字段标签、空状态、细滚动条、浮层描边与投影。组件不再各写一套内联样式。

11. 顶栏品牌位换成 cislunar space 标志。标志取自品牌母版 `tools/assets/logo.png`，缩到 128px 的副本入库（`frontend/src/assets/cislunar_logo.png`）。标志是深藏青描边配银灰球体、透明底，缩小后描边变淡，所以统一垫一块白色圆角底衬，浅色下再补一条描边交代边界。

## 后果

- 视觉：亮色是默认口径，暗色与之同构。参照项目在白底页面里用灰底卡片分层，本工具反过来：页面与卡片同为白底，面板（侧边栏与停靠面）用一档灰差（`#fafafa`），卡片落在面板上靠 1px 描边分开，页面与卡片本身不相邻，不靠第三种底色区分。
- ADR 0020 中被取代的条目：2px 直角、开关去胶囊、深蓝主色。被保留的条目：关闭位移缩放、彩色只留给状态、深色主题。
- 画布选中与时间轴当前时刻的读数、已走过的一段改用信息蓝（`--tod-accent` 指向 info）。中性主色在深色星图与浅色图表上都不适合承担“当前选中”的点位强调，容易读成禁用态。时间轴滑钮保持中性，避免同一控件出现第三种颜色。
- 所有面板与弹窗的内联样式按新令牌改写。组件测试断言行为与 `data-testid`，令牌测试断言色板与圆角的契约，两者的改动面互不重叠。
- 代价：因为不引入 Tailwind 与 shadcn，无法直接复用它的组件实现，只能对齐令牌与构件范式。若后续需要复刻 shadcn 组件，另立 ADR。

## 备选方案

- 引入 Tailwind v4 与 shadcn 组件：与 antd 的样式体系并存会互相覆盖，构建链路与包体积增加，且要重写全部表单控件，收益不足以抵消回归风险。
- 只换色板、保留直角：层次问题主要出在圆角与投影，单独换色达不到参照项目的质感。
- 照搬参照项目的布局：桌面控制台里画布、参数停靠与助手边栏三面并存，参照项目的居中单列布局放不下这些常驻面板。
